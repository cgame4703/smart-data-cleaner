

\# Smart Data Cleaner



A Python Flask web application that helps users clean CSV and Excel files through a simple web interface.



\## Features



\- Upload CSV and Excel (.xlsx) files

\- Preview dataset rows

\- Remove duplicate rows

\- Trim extra spaces from text

\- Handle missing values

\- View before-and-after cleaning statistics

\- Download cleaned data as CSV or Excel



\## Technologies



\- Python 3.12

\- Flask

\- Pandas

\- HTML and CSS

\- OpenPyXL



\## Run Locally



1\. Clone or download this repository.

2\. Create and activate a virtual environment.

3\. Install dependencies:



&#x20;  pip install -r requirements.txt



4\. Start the application:



&#x20;  python app.py



5\. Open http://127.0.0.1:5000 in your browser.



\## Sample Dataset



Use `sample\_data.csv` to test the cleaning features.
